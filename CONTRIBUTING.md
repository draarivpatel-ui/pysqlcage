# Contributing

Contributions are welcome. Please keep the project zero-dependency, typed, and compatible with Python 3.9 through 3.13.

## Development setup

Use a source checkout and run tests with only the standard library:

```bash
PYTHONPATH=src python3 -m unittest discover -s tests
```

## Rules for changes

- Never interpolate untrusted values into SQL text.
- Keep identifier validation strict and ASCII-only.
- Preserve immutable fragment and schema semantics.
- Add regression tests for every security fix.
- Keep runtime dependencies empty.
- Do not use Python syntax newer than Python 3.9.
- Do not commit generated bytecode, build output, virtual environments, or local machine paths.

## Pull requests

- Describe the threat or bug being fixed.
- Include the exact tests run.
- Keep unrelated refactors out of security fixes.
- Update documentation when behavior changes.
